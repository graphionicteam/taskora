# Taskora — Design Tokens (Approved Reference)
## Color
- Core Refined Indigo: `#4F46E5`.
- HIMI Electric Violet: `#8B5CF6`; accessible light-theme text/action violet: `#6D28D9`; dark-theme accent/text: `#A78BFA`.
- White/light consumer-style surfaces; refined neutral grays; accessible dark theme with matching semantic status and priority. Use only approved Stage 02 full palette. **Do not treat illustration-only colors or unspecified hex values as newly approved tokens.**
- Color cannot be the only status indicator. Maintain WCAG 2.2 AA contrast targets; validate combinations in implementation.

## Typography
- Family: **Plus Jakarta Sans** exclusively for Taskora text/UI; weights 400/500/600/700.
- Body desktop: **14px / 22px**, mobile: **16px / 24px**. Use locked Stage 03 scales for all other heading/label sizes, tracking, and text behavior. Responsive, scalable, readable, no truncation of essential controls.

## Spacing and layout
- Base unit **4px**; standard increments 4, 8, 12, 16, 20, 24, 32, 48 px.
- Sidebar 248px expanded / 72px collapsed; header 64px; desktop content padding 24px; tablet 20px; mobile 16px; dashboard maximum content width 1600px.
- Task panel 520px preferred, 440–680px when resizable; switch to overlay/full screen rather than squeezing content.
- Default task row **52px target**; table header **44px**; standard button/input **40px**, small 32px, large 48px.
- Radii: small 6px; medium 8px; large 12px; extra-large 16px; pill 9999px.
- Standard card padding 20px. Touch interaction areas aim 44–48 logical px even when visuals are more compact.

## Logos and visual identity
- A1 Interlocking Layers, solid flat 2D `#4F46E5` mark, softly rounded connected geometry, no gradient/glass/3D; title-case **Taskora** wordmark in Plus Jakarta Sans. HIMI identity separate. Final production-ready logo vector/export assets will require asset validation from the approved visual concept; imagery isn't implicitly an editable vector master.
